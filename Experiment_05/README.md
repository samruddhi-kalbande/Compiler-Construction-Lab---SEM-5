## Aim
Conversion of lowercase to uppercase and vice versa.

## Description
This LEX program reads the input and converts all lowercase letters to uppercase and all uppercase letters to lowercase. Non-alphabetic characters remain unchanged.

## How to Run
```bash
lex exp5.l
cc lex.yy.c -ll
./a.out
```
Enter text and press `Ctrl+D` to see the converted output. You can also pass a file:
```bash
./a.out input_file.txt
```
