## Aim
Introduction to LEX tool, metadata and patterns.

## Description
This program demonstrates the basics of the LEX tool by recognizing different character patterns (vowels, consonants, digits, spaces, special characters) and printing metadata about the input.

## How to Run
```bash
lex exp1.l
cc lex.yy.c -ll
./a.out
```
Enter text and press `Ctrl+D` (Linux/Mac) or `Ctrl+Z` (Windows) to see the results.
